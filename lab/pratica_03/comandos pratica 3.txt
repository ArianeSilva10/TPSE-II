No terminal da BeagleBone, abra um editor como nano para criar o script:


nano leds_blink.sh

3. Escreva o Script

#!/bin/bash
for i in {0..3}; do
    echo 1 > /sys/class/leds/beaglebone:green:usr$i/brightness
    sleep 1
    echo 0 > /sys/class/leds/beaglebone:green:usr$i/brightness
done


4. Salve o Arquivo
No nano, pressione Ctrl + O para salvar e Ctrl + X para sair.


5. Dê Permissões de Execução
Torne o script executável:

chmod +x led_control.sh

6. Execute o Script
Execute o script diretamente no terminal:

./led_control.sh

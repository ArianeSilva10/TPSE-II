#!/bin/bash

# Função para enviar comando
send_command() {
    i2cset -y 2 0x27 $1
    sleep 0.1
}

# Inicialização do LCD
echo "Inicializando LCD..."
send_command 0x30
send_command 0x30
send_command 0x30
send_command 0x20

send_command 0x28  # 4-bit mode, 2 linhas

send_command 0x01  # Clear display

1. **Por que usar I2C para comunicação com o LCD?**
- O I2C permite comunicação com apenas 2 fios (SDA e SCL)
- Reduz o número de pinos necessários comparado à interface paralela
- Permite conectar múltiplos dispositivos no mesmo barramento
- É um protocolo robusto e bem estabelecido para comunicação serial

2. **Explique o significado de LCD_ADDR 0x27:**
- É o endereço I2C do módulo LCD
- O endereço 0x27 (39 em decimal) é o endereço padrão do módulo PCF8574 que controla o LCD
- Este endereço pode ser alterado através de jumpers no módulo

3. **Por que usamos máscaras de bits (LCD_BACKLIGHT, LCD_ENABLE, LCD_RS)?**
- LCD_BACKLIGHT (0x08): Controla a luz de fundo do display
- LCD_ENABLE (0x04): Sinaliza ao LCD para ler os dados
- LCD_RS (0x01): Diferencia entre comandos (0) e dados/caracteres (1)

4. **Por que existem diferentes delays no código?**
- PULSE_DELAY (500μs): Tempo necessário para o LCD reconhecer o pulso de Enable
- CMD_DELAY (1000μs): Tempo de processamento entre comandos
- INIT_DELAY (4500μs): Tempo necessário para inicialização segura do LCD
- TEXT_DELAY (1000000μs = 1s): Tempo de exibição de cada mensagem

5. **Como funciona a função lcd_pulse()?**
- Gera um pulso no pino Enable do LCD
- Segue a sequência: baixo -> alto -> baixo
- É necessário para que o LCD leia os dados do barramento

6. **Por que o LCD usa modo 4 bits?**
- Economiza pinos de comunicação
- É suficiente para a maioria das aplicações
- Cada byte é enviado em duas partes (nibbles)

7. **Explique a sequência de inicialização do LCD:**
- Espera inicial para estabilização
- Sequência específica {0x03, 0x03, 0x03, 0x02} requerida pelo datasheet
- Configuração do modo 4 bits, 2 linhas
- Configuração do display, cursor e modo de entrada

8. **Como é feito o tratamento de erros no código?**
- Verificação de erros na abertura do barramento I2C
- Verificação na configuração do endereço do slave
- Verificação na inicialização do LCD
- Uso de perror() para mensagens de erro descritivas

9. **Como funciona o cálculo da posição central do texto?**
```cpp
int start_pos = (16 - text_len) / 2;
```
- 16 é o número de colunas do LCD
- text_len é o comprimento da string
- A diferença dividida por 2 centraliza o texto

10. **Por que usar std::vector para armazenar os textos?**
- Facilita o gerenciamento dinâmico dos textos
- Permite adicionar/remover textos facilmente
- Oferece acesso sequencial eficiente
- É uma estrutura de dados segura e flexível
